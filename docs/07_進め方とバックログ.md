# 進め方とバックログ

更新日：2026-11-06

趣味のアプリなので、アジャイルに進める（2026-11-05、作者の方針）。全部の部品を比較・計測してから組み立てるのではなく、毎回「実機に入って触れる版」を作り、使って気づいたことで次にやることを決める。

## 原則

- **毎回、使える版で終える**：1回の区切り（イテレーション）は数時間〜数日の大きさにし、終わりに実機へ入れて作者が触れる状態にする。
- **まず一番簡単に動く方法で通す**：音声認識・OCR・実行先（CPU/GPU）は、確実に動く1つの実装で最初に端から端まで通す。比較や作り込みは、実際に使って遅い・読めないと感じた箇所だけ行う。
- **評価は作者の観点で測る**：画面翻訳は、保存したスクリーンショットと正解で、セリフを全部認識できたか・重ねた訳に欠けがないか・吹き出しを1まとまりで訳せたかを測る（`docs/05_画面翻訳.md`「評価」）。数値は次の判断を変えるときに測り、要約を `docs/00_現在地.md`、詳細を該当する設計書に残す。
- **差し替えられる形は保つ**：エンジンはインターフェースの裏に置く。ただし使わない実装を先回りして作らない。
- **バックログは並べ替えてよい**：下の順番は現時点の案。使ってみた結果で入れ替え、変えたら理由を一言残す。
- **設計書は実装に合わせて直す**：実装で変えた箇所は、その区切りの終わりに設計書へ反映する。

## バックログ（使ってみてから優先度を決める）

画面翻訳：

- 英語の漫画を作者に実機で確かめてもらう。正解を付け、点数で追えるようにする（評価データは2026-11-06に捨てたので、スクリーンショットから用意し直す）
- 画面翻訳の生成を速くする：複数のまとまりを同時に生成（llama.cppの複数シーケンス）、見えている範囲を優先、表示更新の間引き。1画面の時間の大半は生成
- APKを小さくする（正式版で約80MB。内訳は `docs/02_アーキテクチャ.md`「APKの中身」）。ONNX Runtimeが漫画用OCRとsherpa-onnxの中に2つ入っているので、1つにまとめるのが一番効く。CPUの7つの版のうち、古い世代を外す手もある
- 縦書きの残る読み落とし（スマホ画面内の小さな横書き、縦の長音）。`docs/05_画面翻訳.md`「残る問題」
- 訳先の言語を日本語以外にする設定（要件にあるが、今は日本語に固定）
- 画像を直接読んで訳す視覚言語モデル。OCRの読み落としが専用OCRでも直らない場合に比べる。端末内の数B規模では画像の処理に数秒かかり、文字の位置（重ね表示に必要）を返す精度と日本語訳の質がPLaMoの組み合わせに劣るため、最初は採らない

会話翻訳：

- 新しいカードの頭の語の欠け（試験音声で起きた）。実際の声で起きるかを見る
- 翻訳に直近の会話を文脈として渡す。KVキャッシュの先頭再利用、会話の履歴と文脈の渡し方の改善も合わせて考える（`docs/03_翻訳コア.md`「履歴と文脈の使い分け」）
- フォアグラウンドサービス（画面を離れても聞き続ける）
- アプリ内で会話の履歴を見返す画面。会話ログの共有とMarkdownでの保存は2026-11-06に作った（ログはアプリ内に残さない）。相手言語の自動・手動の切り替えも、イテレーション4で作った
- 音声認識エンジンの比較（Nemotron 3.5 ASR Streaming、Qwen3-ASR、SenseVoice）。最初のエンジンの精度や遅延に不満が出たら行う。`docs/04_会話翻訳.md`
- 長時間稼働の発熱対策（省電力モード）

カメラ翻訳（`docs/10_カメラ翻訳.md`「残る問題」）：

- 番号の点を落とした行の扱いを直した版の実機確認、赤い見出しの帯が直前の項目と同じ段落になる問題
- 2Bで一時停止から全部の訳がそろうまでの時間（4件で約8秒）を縮める
- 縦書き（今は扱わない）

共通：

- 翻訳モデルの既定（0.8Bか2Bか）を、会話翻訳で2Bの途中訳が追いつくかで決める
- 配った端末での動作確認。Snapdragonの1〜2世代前（Adreno 740・750）でGPUが動くか、Snapdragon以外でCPUの速さが使える範囲か。遅ければ、CPUの端末では途中訳を間引くなどの軽い動きを足す（`docs/08_リスクと未決事項.md`）

終わったもの：

- 設定画面（2026-11-06。翻訳モデルの選択と2Bのダウンロード。`SettingsActivity`）。モデルの初回ダウンロードも同じ日に作った

## 最初の実装の選び方と、その後の変更

各機能の最初の実装は「確実に動くこと」を優先して選び、使って不満が出たものだけ変えた。

| 機能 | 最初の実装 | 現在 |
| --- | --- | --- |
| 翻訳の実行先 | CPU（KleidiAI有効） | GPU（OpenCL）。REDMAGICのCPUクロック上限のため（2026-11-05） |
| 量子化 | Q4_K_M | Q4_K_Mのまま。GPUではQ4_0と速さが同程度 |
| 翻訳モデル | 0.8B | 0.8B（既定）と2Bを選べる。作者は2Bを使っている（2026-11-06） |
| 画面OCR | ML Kit（日・韓・中） | ML Kit（日・韓・中・英字）＋漫画用OCR（PP-OCRv6 manga） |
| 音声認識 | sherpa-onnxのSenseVoice Small＋Silero VAD | 同じ（2026-11-06に実装。作者の評価は「音声入力の正確さは結構いい」）。疑似ストリーミングで途中の文字も出す |
| カメラ翻訳のOCR | ML Kit（画面翻訳と同じ `MultiScriptOcr`、1行ずつ） | 同じ。コマをまたぐ追跡と多数決を足した（2026-11-06） |
